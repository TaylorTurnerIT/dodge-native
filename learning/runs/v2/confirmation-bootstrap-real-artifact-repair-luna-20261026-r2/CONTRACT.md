# Confirmation bootstrap adapter r2

`adapter.analyze` accepts caller-supplied raw bytes and external SHA-256 pins for final registration, selection record, successful parent terminal audit, and both evaluator result files. It performs no filesystem reads, writes, runtime imports, or checkpoint reads. Import NumPy only. Results use actual `expanded_D2_candidate_evaluation_v1` rows; rows must cover ordered D2000000..D20007FF and conserve terminal/truncation frames, native death causes, and caps.

Registration must be `expanded_D2_evaluation_registration_v1` in confirmation mode. Confirmation manifest pin must be the frozen 2048-seed manifest SHA `d2594d710820ee2942aff20a11ca4dd049f1d605f6cce2950ce0018a71994d67`. Selection bytes must match registration `selection_record` path/hash/fields and schema `expanded_D2_selection_record_v3`; winner must be frozen update 324 and match registered checkpoint identity. Comparator must be accepted update 348 at checkpoint `b95228e5e2934c915597595f7eb3c8618ee5f7c2182dde1481a060d01c270369`. This function binds only that identity; it does not independently regenerate ranking selection.

Both raw result files must match caller SHA pins and bind update, checkpoint, confirmation manifest hash, cohort, backend, and all evaluator rows. Audit bytes must match their caller pin and the provisional `parent_expanded_confirmation_terminal_audit_v1` contract: accepted evidence only, exact run and registration hashes, zero supervisor/worker exits, absent process group, no promotion, and exactly both absolute result paths and raw-file SHA pins.

Statistics use 20000 PCG64(4200261026) resamples, each drawing 2048 seed indices. Paired differences share each draw. Quantile is linear at 0.05; chunks of 128 preserve one generator stream. Report Worst, Q1 bottom 512 mean, Mean, Q4 top 512 mean, Best, native death counts, and caps. `LB > 0` alone yields eligible; `LB <= 0` yields inconclusive. Neither result grants promotion, retry, or ledger authority.

The terminal-audit schema above is provisional, pending parent registration/integration/review. This preparation has no real final registration, result files, or successful terminal audit. It does not read ranking episode output files. Tests use toy in-memory evaluator-shaped rows only.
