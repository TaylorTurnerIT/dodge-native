Progress timing successor to the accepted progressive1000 worker. Model, PPO,
native binary, rewards, seeds, restore and curriculum runtime bytes are unchanged.
The worker times collection, collection journaling, PPO, metric writes and
checkpoints; stdout carries five-second progress samples and update boundaries.
Forecasts warn without changing limits or learning. Every guard still reads the
ledger bytes; strict parsing is cached only for identical contents.

Repeated cumulative history dumps before PPO are removed. Returned-work events,
integrity checkpoints and terminal snapshots remain. A separately registered
24-update control timing probe cannot provide a formal comparison endpoint.
The comparison remains 60 updates per arm. Registrations, review, exact leases,
one-use markers and terminal parent audits remain required. No automatic retry,
endpoint selection, promotion or qualification is authorized by this package.
