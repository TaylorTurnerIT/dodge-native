LucasHow it works

velocity-flow-v2: a learned danger map

The network never picks a move. It draws where danger will be; fixed arithmetic turns that map into a move.

Observation

One frame on a 32×32 grid of 4px cells.

11 channels: 8 object types, player, x and y velocity

+ 10 numbers: player position, velocity, nearest-threat geometry

→

Conv trunk

3×3 conv at 32×32, then three at 16×16, one dilated to reach across the arena. A 4×4 pooled summary is blended back so every cell sees the whole arena.

11 → 32 → 64 → 64 → 32 channels · ~80k weights

→

Danger field

A 1×1 conv gives six danger maps, one per moment in the future.

+4, 12, 24, 48, 72, 108 frames

↓
↓

Because the output is a picture, the field can be drawn behind the game while you watch it play.

Critic

Trunk channel means, an 8×4×4 coarse map of the arena, and the player numbers go into a small MLP.

32 + 128 + 10 → 64 → 64 → value

Controller

For each of the 9 moves, look up where it takes the player at each future frame and read that frame's map there. Sum the readings, then standardise across moves.

× learned sharpness → 9 action logits

Learned weightsFixed rulePPO, γ 0.997, one decision per frame
Lineage: MLP → hybrid CNN (87% of its weights in one flatten layer, which also died) → field-cnn (fully convolutional field) → VelocityFlow (velocity raster instead of a frame stack) → v2 (critic gets a coarse map; trunk middle at 16×16 for speed).

Two dense layers.

→

One state value plus nine advantages.

Q = V + A − mean(A)

→

Controller

Steer toward the chosen relative waypoint and hold it.

The entity-transformer teacher

Instead of a picture, it sees a list of objects, and attention lets each object weigh the others.

Global token

Player position, velocity and size, freeze rate, speed, enemy count, score, pattern visibility, distances to walls.

14 → 128 linear

+

Entity slots

Each enemy, blast, powerup and pattern box: centre and half-size, relative position, motion, signed gaps, contact time, time until lethal. A type ID says what it is; a mask marks empty slots.

64 enemy + 16 box slots × 16 → 128 GELU → 128 + type embedding

→

Transformer

1 global + 80 entity tokens, pre-norm self-attention, no positional embedding, then a final LayerNorm on the global token.

2 layers · 4 heads · width 128 · FF 256

↓

No pixels, no future spawns, no hidden timers. 321,290 weights in all. The plan was to distill it later into a student that sees only the screen.

M0 plays on

up to 192 frames
