Every way we tried to play Dodge

A timeline of the learned models, hand-written bots and search planners behind the PICO-8 game Dodge.

  Lucas (LaunchSpark): DodgeAI   Taylor Turner: rl-learning, dodge-ai-3, dodge-native
Dodge is Artridge's PICO-8 cartridge (CC BY-NC-SA). Two parallel efforts, merged into one repository (dodge-native) in November. Waypoint DQN: pick a place, not a direction

The network scores nine nearby targets; fixed code does the steering and holds the choice for 32 frames. Commitment beat the collapse.

Observation

Player position, velocity and size. 16 enemy and 8 blast slots, sorted by estimated time to contact, then distance: presence, time to contact, relative position, velocity, size, stage. Grid cell and overflow flags.

225 = 5 + 24 × 9 + 4

→

Trunk

Two dense layers.

225 → 256, LayerNorm, ReLU · 256 → 256, ReLU

→

Dueling heads

One state value plus nine advantages.

Q = V + A − mean(A)

→

Controller

Steer toward the chosen relative waypoint and hold it.

9 waypoints · 8 decisions · 4 frames each

Learned weightsFixed ruleDouble DQN
Double DQN, 3-step returns, γ 0.99, replay 100k, batch 256, lr 1e-4, target sync 1,000. A 5 × 5 waypoint grid, but nine relative-waypoint outputs, not 25. Empty slots are zero-filled. The manifest says the native encoder matched the Python reference. The best checkpoint's layers were inspected with a safe weights-only load.

LucasAct IIIAug 23 · How it works

velocity-flow-v2: learned danger, coded player

The weights draw where danger will be. Fixed code knows exactly where each move takes the player, and reads the map there.

Observation

One frame on a 32×32 grid of 4px cells.

11 channels: 8 object types, player, x and y velocity

+ 10 numbers: player position, velocity, nearest-threat geometry

→

Conv trunk

3×3 conv at 32×32, then three at 16×16, one dilated to reach across the arena. A 4×4 pooled summary is blended back so every cell sees the whole arena.

11 → 32 → 64 → 64 → 32 channels · ~80k weights

→

Danger field

A 1×1 conv gives six danger maps, one per moment in the future.

+4, 12, 24, 48, 72, 108 frames

↓
↓

Built-in limits: the path ignores the player's current momentum; with a 4-frame hold the far slices all read about the same point 10 px out; standardising makes one move look bad even in an empty arena.

Critic

Trunk channel means, an 8×4×4 coarse map of the arena, and the player numbers go into a small MLP.

32 + 128 + 10 → 64 → 64 → value

Controller

The cartridge's movement model, from rest with the button held 4 frames, gives each move's position at each slice's time. Read that slice there, weight by 0.985t, sum, standardise across moves.

× learned sharpness → 9 action logits

Learned weightsFixed rulePPO, γ 0.997, one decision per frame
Lineage: MLP → hybrid CNN → field-cnn → VelocityFlow → v2 (critic gets a coarse map; cheaper trunk). The movement model matches the live cartridge exactly over 24 frames. velocity-flow-v3 fixes the three built-in limits but hasn't been trained yet.
